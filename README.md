# interactor-test-fbx-opengameart

Public-domain test models in `.fbx` form from a free game-art archive, each with `.obj` snapshots and a record of its source.

## Use

Each directory is named for an asset's author. A model ships as `.fbx` beside gzipped `.obj` snapshots of its mesh, some taken at named animation frames. A `.json` file records each asset's title, author, source page and licence.

## Build and run

Nothing here builds. The files are test data.

## Licence

Every asset is CC0 1.0, as its `.json` record states. The repository states no licence of its own.
